# 📘 Smart Attendance Management System (SIH Project)

A full-stack web application developed using the MERN stack (MongoDB, Express.js, React.js, Node.js) for efficient and secure attendance management in schools.

This project was built as part of the **Smart India Hackathon (SIH)** initiative, aiming to modernize traditional attendance systems with a scalable digital solution.

---

## 🚀 Features

- 👨‍🏫 Teacher Login with Location Verification (GPS-based simulation)
- 📍 Secure attendance marking (prevents unauthorized access)
- 🧑‍🎓 Class-wise student attendance system
- 🔒 One-time final submission (attendance lock)
- 📊 Attendance history tracking
- 🛠 Admin panel to manage teachers and students
- 🌐 Fully responsive web interface using React

---

## 🛠 Tech Stack

- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB Atlas  
- **API Handling:** Axios  

---

## 🎯 Key Highlights

- Eliminates manual attendance errors
- Prevents duplicate and proxy attendance
- Real-time data storage and retrieval
- Role-based system (Teacher/Admin)
- Simulated GPS verification for enhanced security
