# Smart Attendance Management System

A MERN-stack attendance platform developed as a Smart India Hackathon project.

## Features
- Teacher login with simulated GPS/location verification
- Secure attendance marking
- Class-wise student attendance
- One-time attendance submission and locking
- Attendance history
- Teacher and admin workflows
- Responsive React interface

## Stack
React.js, Node.js, Express.js, MongoDB Atlas, and Axios.

## Goals
Reduce manual attendance errors, prevent duplicate/proxy submissions, and provide centralized attendance records.

Check the frontend and backend directories for their individual dependency configuration and start commands.
